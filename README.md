# [R4tel.de](https://r4tel.de) - Nachbarschaftsverein in Berlin-Lichtenberg

## Änderungen + Hinweise

#### April 2026
Die Bezeichnung "r4tel" wird in Zukunft ausschließlich durch den Verein r4tel e.V. weiterverwendet. Die bisher den Namen "r4tel" nutzende Nachbarschaftsgruppe nennt sich in [RathausKiez](https://github.com/RathausKiez) um und verwendet ab sofort die Domain [rathauskiez.de](https://rathauskiez.de) (und rkiez.de). Die von der Nachbarschaftsgruppe zusammengestellten Inhalte werden von der Vereinswebsite gelöscht.

#### März 2022
Nachdem wir anfangs nur eine README.MD hatten, sind die Inhalte nun auf mehrere Seiten aufgeteilt:
* `index.md` ist die frühere, aber entschlackte, `README.MD`, und wird weiter unter https://r4tel.de angezeigt
* Auf die anderen auf `.md` endenden Seiten wird von der `index.md` verwiesen (wie das geht ist auf der `index.md` zu sehen).
